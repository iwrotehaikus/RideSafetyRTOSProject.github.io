📌 Project Overview

This project demonstrates a proof-of-concept real-time embedded system built on the ESP32 running FreeRTOS. The system simulates a theme-park roller coaster safety node with:

  • Real-time load sensor monitoring (Hard/Firm RT)
  • Emergency Stop ISR + latency-critical brake response
  • Alert queue + safety LED logic
  • Telemetry logger with variable execution time
  • Heartbeat LED for deterministic operation
